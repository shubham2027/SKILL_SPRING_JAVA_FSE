# myfirstreact - Week 5 Exercises

This React application contains all completed hands-on exercises for Week 5.

## Exercises Summary

1. **Welcome to React**: Basic React rendering.
2. **Home / About / Contact Components**: [Home.js](src/components/Home.js), [About.js](src/components/About.js), [Contact.js](src/components/Contact.js)
3. **Score Calculator App (`CalculateScore`)**:
   - Component: [CalculateScore.js](src/components/CalculateScore.js)
   - Stylesheet: [mystyle.css](src/Stylesheets/mystyle.css)
4. **Blog App (`Posts`)**:
   - Model: [Post.js](src/Post.js)
   - Component: [Posts.js](src/components/Posts.js)
5. **Cohort Details Dashboard (`CohortDetails`)**:
   - CSS Module: [CohortDetails.module.css](src/components/CohortDetails.module.css)
   - Component: [CohortDetails.js](src/components/CohortDetails.js)

---

## How to Run

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the app in the browser.
