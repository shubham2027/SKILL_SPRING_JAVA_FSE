# DN 5.0 - Training Curriculum & Complete Exercises

This repository contains the complete hands-on learning exercises and projects implemented for the **DN 5.0** training program, organized by week.

---

## Workspace Directory Structure & Week-Wise Completeness

### [Week 1](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%201): Java Core & Foundations
Focused on algorithms, design patterns, testing, database scripting, and logging.
- **[Data Structures & Algorithms](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%201/DataStructureAlgorithm)**: Implementations of search, sort, and optimization algorithms.
- **[Design Principles & Patterns](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%201/DesignPrinciplePattern)**: Code examples illustrating SOLID principles, Creational, Structural, and Behavioral patterns.
- **[Logging with SLF4J](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%201/LoggingUsingSLF4J)**: Setting up standardized logging practices using SLF4J and Logback.
- **[PL/SQL Programming](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%201/PLSQLProgramming)**: PL/SQL scripts, cursors, stored procedures, triggers, and functions.
- **[TDD with JUnit](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%201/TDDUsingJunitExercises)**: Test-Driven Development (TDD) exercises using JUnit framework.

---

### [Week 2](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%202): Spring Core & ORM Foundations
Focused on standard Spring framework dependency injection and JPA/Hibernate mapping.
- **[Spring Core & Maven](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%202/SpringCore_Maven)**: Basic Maven setups, IoC container, bean configurations, scope, and DI.
- **[Spring Boot, JPA, & Hibernate](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%202/SpringBoot_JPA_Hibernate)**: Mapping entities, repositories, and bootstrapping APIs with Spring Boot.

---

### [Week 3](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%203): Spring Learn & Microservices
Hands-on exercises detailing microservices structure.
- **[spring-learn](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%203/spring-learn)**: Microservice concepts, REST controllers, properties injection, validation, and testing.

---

### [Week 4](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%204): Banking & Financial APIs
Implementation of microservices registered under a central Service Discovery registry.
- **[eurekadiscoveryserver](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%204/eurekadiscoveryserver)**: Spring Cloud Netflix Eureka Discovery Server running on port `8761` for client service registration.
- **[account](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%204/account)**: Microservice managing checking/savings bank account details, registered with Eureka client.
- **[loan](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%204/loan)**: Microservice managing loan profiles, EMIs, and terms, registered with Eureka client.

---

### [Week 5](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205): Frontend Development with React
A series of React.js frontend exercises ranging from single-page components to multi-component conditional logic apps.
- **[myfirstreact](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/myfirstreact)**: Exercises 1 to 7 (Basic navigation, Score Calculator, Fetching JSON API data with Class components, CSS Module Styling, SPA Router Trainers, and Table render).
- **[counterapp](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/counterapp)**: Exercise 8 (Class-based state counter monitoring Entry/Exit count).
- **[cricketapp](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/cricketapp)**: Exercise 9 (Displays lists of players utilizing ES6 `.map()`, `.filter()`, array destructuring, and spread array merge, conditionally rendering with a flag switch).
- **[officespacerentalapp](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/officespacerentalapp)**: Exercise 10 (JSX elements, dynamic attributes, objects rendering, and mapping arrays, with conditional Red/Green CSS text coloring based on rent amounts).
- **[eventexamplesapp](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/eventexamplesapp)**: Exercise 11 (State, Synthetic events, argument passing, and Euro to Rupee Currency Converter).
- **[ticketbookingapp](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/ticketbookingapp)**: Exercise 12 (Conditional rendering of ticket booking form based on login status).
- **[bloggerapp](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/bloggerapp)**: Exercise 13 (Multi-conditional page layout rendering).
- **[employeemanagementapp](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/employeemanagementapp)**: Exercise 14 (Theme context sharing with Context API without prop drilling).
- **[ticketraisingapp](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/ticketraisingapp)**: Exercise 15 (Class component form validation and transaction ID generation).
- **[mailregisterapp](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/mailregisterapp)**: Exercise 16 (Registration form input validation via event handling and submit alerts).
- **[fetchuserapp](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/fetchuserapp)**: Exercise 17 (Class component fetching random user details asynchronously on load).
- **[myfirstreact (Tests & GitClient)](file:///d:/CODES/SKILL%20SPRING%20JAVA%20FSE/Week%205/myfirstreact)**: Exercises 18 and 19 (Unit testing CohortDetails component using Enzyme/Jest and mocking Axios API requests for GitClient).
