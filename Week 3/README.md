# Week 3

The Week 3 work is completed in [spring-learn](spring-learn).

## Hands On Covered

1. Spring Web project created with Maven.
2. SimpleDateFormat loaded from Spring XML config using [date-format.xml](spring-learn/src/main/resources/date-format.xml).
3. Logging added through SLF4J and `application.properties`.
4. Country bean loaded from Spring XML config using [country.xml](spring-learn/src/main/resources/country.xml).

## Project Files

- [SpringLearnApplication.java](spring-learn/src/main/java/com/cognizant/springlearn/SpringLearnApplication.java)
- [Country.java](spring-learn/src/main/java/com/cognizant/springlearn/Country.java)
- [application.properties](spring-learn/src/main/resources/application.properties)
- [date-format.xml](spring-learn/src/main/resources/date-format.xml)
- [country.xml](spring-learn/src/main/resources/country.xml)

## Run

From the `spring-learn` folder:

```bash
mvn clean package
```

Then run [SpringLearnApplication.java](spring-learn/src/main/java/com/cognizant/springlearn/SpringLearnApplication.java).
